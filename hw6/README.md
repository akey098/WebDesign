# COM360 Assignment 6 — MercyMed Website (First Draft)

A static, responsive, AI-assisted first draft. Open `index.html` locally to preview; upload the `hw6` directory to your GitHub Pages repository to publish.

## Files
- `index.html` — page content and sections (About, Services, Programs, Team, Contact).
- `styles.css` — responsive layout and design tokens.
- `script.js` — English, Kyrgyz, Russian translations and mobile navigation.

## Before final submission — required client checks
The instructor's presentation specifies the official MercyMed brand palette and questionnaire, but the short links were inaccessible during this build and the team PRD was not provided. **Do not claim this draft is brand-compliant until the following have been verified:**

1. Compare all CSS tokens at the beginning of `styles.css` with the official palette at https://com360.short.gy/MercyMedBrand and replace *all* unspecified colors, including tints, borders and shadows, if the brand guide forbids them.
2. Compare the content, services, programs, language, contact information and design against https://com360.short.gy/MercyMedOnePager and the team's PRD. Replace provisional service and program content, and add approved team members, photos and brand logo.
3. Confirm the clinic's name, physical address, phone, email, hours, appointment process and all map links. Avoid publishing unverified contact info.
4. Verify language translations with a proficient speaker.
5. Test desktop and mobile screens; verify that navigation and language switching work.

No fake clinician profiles, quotes, appointment systems or contact details have been invented. The service descriptions are clearly marked provisional.
