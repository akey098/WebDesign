# MercyMed — Assignment 7 (v2)

This version is based on `hw6` and addresses peer-review feedback and the team's MercyMed PRD.

## Changes
- Brand palette updated from green/teal to logo-aligned orange/yellow and grey.
- Navigation: Home, About, Medical Services, Team, Contact.
- Booking CTAs in header, hero and Contact, opening a WhatsApp message preview **clearly marked as a student prototype**.
- Four Medical Services cards: consultations, diagnostics, ultrasound and laboratory tests, with different inquiry links.
- Team content expanded without inventing staff names or using unapproved photographs.
- Tunguch / Ayu Grand approximate location, plus Phone, Email, WhatsApp placeholders.
- Map opens the *Ayu Grand landmark*, NOT a claimed MercyMed map pin.
- Contact card foreground text contrast improved and mobile responsive layout retained.
- English, Russian and Kyrgyz translations updated; client-language review is still pending.

## Important
This is a classroom prototype, **not a real medical booking system**. The WhatsApp button uses a share-message workflow without a clinic number; it does not contact MercyMed automatically. The clinic's phone/email/WhatsApp, opening hours, exact address, staff names/specialties and real photos must be approved before public use. No patient data is collected. Please confirm translations with a qualified reviewer.

## Pre-submission QA
1. Open `hw7/index.html` locally and inspect header, services, team and contact on desktop and narrow screens (320 / 375 px).
2. Switch EN, КЫ and РУ, and verify the four service cards and booking modal translate.
3. Click all booking buttons; check WhatsApp is labeled demo, not a confirmed clinic chat.
4. Tab through the controls, open and close the booking modal using keyboard.
5. Test the map link and verify it shows Ayu Grand area, not an invented clinic pin.
6. Publish GitHub Pages `hw7` URL and submit to eCourse and Buzz with a bullet list of the changes.
